# Waitlist, reminders or recurring bookings: which problem should come next?

![Waitlist, reminders and recurrence](https://github.com/DimaGutierrez/slotguard/blob/main/assets/discussion-roadmap.png?raw=true)

SlotGuard v0.1 handles room booking, cancellation, conflicts and an isolated race demo. What would make you use it again next week?

| Candidate | Problem | Design cost |
|---|---|---|
| A — Waitlist | A full room becomes available later | Fair ordering, expiry and confirmation |
| B — Reminders | People forget reservations | Delivery, retries and preferences |
| C — Recurrence | A team books the same weekly meeting | Timezones, exceptions and partial conflicts |

These are proposals, not shipped features or promised release dates. The artwork illustrates options.
